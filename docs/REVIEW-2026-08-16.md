## Findings

### 1. CRITICAL — Contact publishes an address that is probably not read

`src/data/mail.ts` assembles **`patrickmcclevarty@outlook.com`**. The address on the client's
Namespro account (seen autofilled 2026-08-16) and on file here is **`patrickmcclevarty@hotmail.ca`**.

Contact is *the one page with a job*, and that address is the job.

```
Reveal control     "Copy the address"  — works
Revealed           patrickmcclevarty@outlook.com
In page source?    no  ✓  (assembled at runtime, as designed)
Expected           patrickmcclevarty@hotmail.ca
```

The mechanism is correct — the address is genuinely absent from markup before the click, so the
anti-scraping rule holds. Only the value is suspect. This has been sitting on the sign-off list
since 2026-08-13 as an open question; it is promoted here because it is the only finding that can
cost the client actual work.

**Blocked on the client**: which mailbox is read.

### 2. HIGH — the tablet band slices "Guestbook" mid-word, with no fade

At **600px** the pill row overflows by **48px** and the last pill renders as `GUEST` with a hard
edge. That is precisely the symptom the 2026-08-14 audit found on the phone band and fixed with a
34px trailing `mask-image` fade — *"a cut letter reads as broken, a fading one reads as
continuing"*.

The fade was then deliberately scoped to `.band-phone` only (`chrome.css:296`), on the stated
premise that a tablet *"fits the six public pills with room to spare"*. **That premise died when
Scams became a seventh pill** later the same day, and the tablet band was never re-measured.

| width | band | overflow | fade | result |
|---|---|---|---|---|
| 600 | tablet | 48px | **no** | **"Guestbook" sliced** |
| 760 | tablet | 0 | n/a | fits |
| 880 | tablet | 0 | n/a | fits |
| 1280 | desk | 0 | n/a | wraps |

Affected range ≈ **560–710px**: a phone in landscape, a small tablet in portrait.

**Recommended fix**: make the fade conditional on the row *actually overflowing* rather than on the
band. That reaches this case without reintroducing what the phone-only scoping was protecting
against — a permanent fade on a tablet row with nothing hidden behind it. Do **not** simply add
`.band-tablet` to the selector: at 760px and up there is nothing to fade, which is the exact bug
the original note describes deleting.

### 3. MEDIUM — on a phone, Contact and Guestbook are both entirely off-screen

The row scrolls and the fade advertises it, so nothing is broken. But the fade was sized against a
**66px** overflow; with seven pills it is **212–242px**, and the two pills past the edge are Contact
and Guestbook.

| width | overflow | fully hidden | cut |
|---|---|---|---|
| 390 | 242px | **Contact, Guestbook** | Gallery |
| 420 | 212px | **Contact, Guestbook** | Gallery |

Contact survives via the home hero's *Fix my computer* CTA. From any other page on a phone, reaching
it means discovering that a row of buttons scrolls sideways.

**Options** (cheapest first): leave it; widen the fade so more of the next pill peeks; or **move
Contact earlier in `NAV`** so the page with a job is never the hidden one. Recommend the last — it
costs nothing and puts ordering where the priority already is. Note `NAV` order is what
`useOperatorRoutes` cycles and what Radial's orbit renders, so a reorder moves both; that is
cosmetic, not structural.

### 4. NOTE — two labels still speak the submarine language the site dropped

`pages.ts:95` `eyebrow: "pressure nominal"` (home) and `pages.ts:641`
`eyebrow: "pressure lost · http 404"`. Both are survivors of the "Vessel" identity that the
de-branding removed everywhere else visible.

Same class as the copy the 2026-08-15 rewrite targeted: short, plain-worded, allusive, and
meaningless to the reader the client named. There is a real argument for keeping them as texture,
which is why this is a note. **Client's call.**

Worth noting against `CLAUDE.md` deviation 8, which records the 404's `pressure lost` variant as
having been removed with the vitals strip — it was removed from the *strip*, but survives as the
page eyebrow. The note reads as though it is gone entirely.
